# Chapter 5 Lab: ML Lifecycle, Evaluation Metrics, and Deep Learning Intuition

**Estimated time:** 30 minutes

## Exercise

Train a scikit-learn classifier, log the run with MLflow, evaluate it with precision/recall/F1, then write a one-paragraph justification for whether the same task could be solved with a rule-based system instead

## Key takeaway

Choose the simplest model that meets the metric the client actually cares about, and track every experiment for reproducibility.
