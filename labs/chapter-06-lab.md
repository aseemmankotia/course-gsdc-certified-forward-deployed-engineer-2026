# Chapter 6 Lab: Prompt Engineering and LLM Workflow Design

**Estimated time:** 25 minutes

## Exercise

Write and test four prompt variants (zero-shot, few-shot, chain-of-thought, structured JSON output) against the same task and compare output quality, cost, and latency

## Key takeaway

Pick the prompting pattern and evaluation method that fits the client's reliability, cost, and latency requirements — not the fanciest technique.
