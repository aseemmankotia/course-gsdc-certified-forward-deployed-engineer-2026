# Chapter 8 Lab: Agentic Systems and Tool Use

**Estimated time:** 25 minutes

## Exercise

Build a simple tool-calling agent that decides between a calculator tool and a search tool, then identify and document a scenario where a simple deterministic chain would outperform the agent

## Key takeaway

Agents add power and unpredictability at the same time — use them only when dynamic decision-making genuinely justifies the cost.
