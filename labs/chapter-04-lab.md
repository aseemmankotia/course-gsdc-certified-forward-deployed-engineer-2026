# Chapter 4 Lab: Data Engineering and Storage Strategy for AI Systems

**Estimated time:** 25 minutes

## Exercise

Design a data pipeline diagram choosing the storage backend (SQL vs NoSQL vs vector DB) for three different client scenarios, then implement a simple batch ETL script in Python that loads, transforms, and stores sample data

## Key takeaway

Match the pipeline pattern and storage backend to the client's actual latency and query needs, not the trendiest tool.
