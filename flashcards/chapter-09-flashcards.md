## Chapter 9: Rapid Prototyping UI and Cloud Deployment — Flashcards

| # | Front (Question) | Back (Answer) |
|---|-----------------|---------------|
| 1 | Gradio gr.Interface with share=True — how long does the public shareable link stay active? | 72 hours, then it expires. Exam tip: for permanent hosting use Hugging Face Spaces or a proper cloud deployment, not the temporary share link. |
| 2 | Streamlit @st.cache_data vs @st.cache_resource — when to use each? | cache_data: for serializable return values (DataFrames, lists, API responses) — copies data per call. cache_resource: for unserializable shared objects (ML models, DB connections) — returns the same singleton instance. Exam tip: caching a loaded model with cache_data will error or behave incorrectly. |
| 3 | Streamlit vs Gradio — core selection rule for the exam | Streamlit: full multi-page data apps/dashboards with rich layout control. Gradio: fastest way to wrap a single ML model with standard I/O components (image, audio, text, chat). Exam tip: 'quick model demo' → Gradio; 'internal dashboard/app' → Streamlit. |
| 4 | AWS Secrets Manager vs SSM Parameter Store | Secrets Manager: built-in automatic rotation, ~$0.40/secret/month, purpose-built for credentials. Parameter Store (Standard tier): free, no native rotation, better for config values/non-sensitive parameters. Exam tip: 'needs automatic rotation' → Secrets Manager. |
| 5 | Serverless container hosting equivalents across clouds | AWS: Fargate (ECS/EKS). Azure: Container Apps. GCP: Cloud Run. Exam tip: all three scale to zero and bill per request/usage, no server management. |
| 6 | Dockerfile syntax: multi-stage build to shrink final image | FROM python:3.12 AS builder ... RUN pip install --target=/app deps FROM python:3.12-slim COPY --from=builder /app /app Exam tip: only the final FROM stage ships; builder-stage tools (compilers, dev headers) are discarded. |
| 7 | Dockerfile layer ordering for cache efficiency | Order instructions least-to-most frequently changing: base image → system deps → COPY requirements.txt → RUN pip install → COPY source code. Exam tip: copying source before installing deps busts the pip cache on every code edit. |
| 8 | HTTP 429 handling pattern for rate-limited APIs | Exponential backoff with jitter + bounded retry count. Never tight-loop retry. Exam tip: exam scenarios describing 'rate limit errors under load' expect this exact pattern as the answer, not synchronous calls. |
| 9 | 12-factor app config principle applied to AI apps | Store config (API keys, endpoints, model names) in environment variables, never hardcoded in source. Exam tip: hardcoded credentials in a Dockerfile or committed .env file is always the wrong answer on secrets-management questions. |
| 10 | Git workflow: feature branch naming and merge process | Create feat/<short-description> or fix/<short-description> branch → commit → open PR → code review → merge to main. Exam tip: never commit secrets in a PR; use pre-commit hooks or secret scanning to catch this. |
| 11 | AWS Secrets Manager pricing structure | Approx. $0.40 per secret per month + $0.05 per 10,000 API calls. Exam tip: cost is a reason teams sometimes choose Parameter Store for non-rotating, non-sensitive config instead. |
| 12 | Docker: difference between an image and a container | Image = immutable, versioned template (built from a Dockerfile). Container = a running (or stopped) instance of an image. Exam tip: `docker build` creates an image; `docker run` creates a container from it. |
