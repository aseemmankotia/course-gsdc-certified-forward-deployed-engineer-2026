## Chapter 5: ML Lifecycle, Evaluation Metrics, and Deep Learning Intuition — Flashcards

| # | Front (Question) | Back (Answer) |
|---|-----------------|---------------|
| 1 | Precision formula and what it measures | Precision = TP / (TP + FP). Measures how many predicted positives were actually correct. Exam tip: optimize precision when false alarms are costly (e.g., spam folder deleting real email). |
| 2 | Recall formula and what it measures | Recall = TP / (TP + FN). Measures how many actual positives were caught. Exam tip: optimize recall when missing a positive is costly (e.g., fraud, cancer detection). |
| 3 | F1 Score formula | F1 = 2 × (Precision × Recall) / (Precision + Recall). Harmonic mean — used when you need a single balance between precision and recall, especially on imbalanced datasets. |
| 4 | MAE vs RMSE — which is more sensitive to outliers? | RMSE squares errors, so large errors are amplified — more sensitive to outliers. MAE averages absolute error linearly — more robust to outliers. Exam tip: pick MAE when outliers should not dominate the reported error. |
| 5 | When to choose rule-based vs ML vs LLM system? | Rule-based: fixed, small, deterministic logic, auditability required. ML (classic supervised): structured data, clear labels, need accuracy/interpretability at scale. LLM: unstructured language tasks, open-ended generation, flexible/ambiguous inputs. Exam tests picking the SIMPLEST solution that meets requirements. |
| 6 | MLflow vs Weights & Biases — key difference | MLflow: open-source, self-hostable, strong on experiment tracking + model registry + packaging. W&B: hosted-first, richer visualization/dashboards, strong for large team collaboration. Exam tip: MLflow = lightweight/open-source fit; W&B = large-team visualization fit. |
| 7 | Standard k values for k-fold cross-validation | k=5 or k=10 are most common defaults. LOOCV (k=n) used for very small datasets to maximize training data per fold, at higher compute cost. Exam tip: small dataset + high variance across folds → consider LOOCV. |
| 8 | Transfer learning — definition and use case | Reusing a model pretrained on a large dataset (e.g., ImageNet) and fine-tuning it on a smaller, task-specific dataset. Use when labeled data is scarce. Exam tip: transfer learning is the standard answer for 'too little data to train a deep model from scratch.' |
| 9 | Attention mechanism — one-sentence definition | Lets a model weigh the relevance of every other token when representing a given token, capturing long-range dependencies in parallel. Core building block of transformers. Exam tip: distinguish from RNNs, which process sequentially and struggle with long-range context. |
| 10 | Tokenization — what it is and why it matters | Splitting text into subword/word units (tokens) that a model's vocabulary can map to IDs before embedding. Common methods: WordPiece, BPE (Byte-Pair Encoding), used by HuggingFace tokenizers. Exam tip: tokenization happens BEFORE embeddings and attention. |
| 11 | MLflow basic experiment logging syntax | ```python import mlflow with mlflow.start_run():     mlflow.log_param("lr", 0.01)     mlflow.log_metric("accuracy", 0.92)     mlflow.sklearn.log_model(model, "model") ``` Exam tip: log_param for hyperparameters, log_metric for results, log_model for the artifact + versioning. |
| 12 | Embeddings — definition | Dense numeric vectors representing tokens/words/items such that semantically similar items are closer in vector space. Foundation for transformers, search, and recommendation systems. Exam tip: embeddings are learned representations, not one-hot encodings — enable semantic similarity comparisons. |
